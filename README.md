# 반려동물 영양연구소

GitHub Pages에 배포할 수 있는 정적 홈페이지입니다.

## 배포 방법
1. GitHub에서 `pet-nutrition`이라는 **Public** 저장소를 만듭니다.
2. 저장소에서 **Add file → Upload files**를 선택합니다.
3. 이 폴더의 `index.html`을 업로드하고 **Commit changes**를 누릅니다.
4. **Settings → Pages**로 이동합니다.
5. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
6. Branch는 `main`, 폴더는 `/(root)`로 설정하고 **Save**를 누릅니다.
7. 잠시 후 Pages 화면의 **Visit site**에서 공개 주소를 확인합니다.

## 참고
- 이 사이트는 HTML/CSS만 사용하는 정적 홈페이지입니다.
- 상담 신청 저장, 회원가입, 데이터베이스 기능은 포함되어 있지 않습니다.
- 건강 정보는 일반 교육 목적이며 수의사의 진료를 대신하지 않습니다.
